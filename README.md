# 나의 비서실

원하는 삶의 방향을 잃지 않으면서, 뇌 리듬(뇌과학 시간표)에 맞춰 하루를 보낼 수 있게 돕는 개인 비서 웹앱입니다.

> 이 앱은 사용자를 더 생산적인 사람으로 만드는 것이 목적이 아니다.
> 사용자가 자신이 원하는 삶을 지속할 수 있도록 돕는 것이 목적이다.

전체 기획과 설계 원칙: [docs/VISION.md](docs/VISION.md)

https://nomadicsyspure-beep.github.io/my-secretary/

## 지금 되는 것 (v0.4)
- **🧭 삶의 방향**: 궁극적인 목표, 세 가지 파이프라인, 삶의 원칙, "기분과 방향은 달라요" (수정 가능)
- **🌤 오늘의 상태 확인**: 에너지 · 신경 쓰이는 것 · 필요한 것 → **오늘의 제안** (크기는 조절하고 방향은 유지)
  - 지친 날엔 모든 블록에서 최소 버전을 기본으로 보여줌
- **🎯 오늘의 한 가지**를 파이프라인과 연결
- **🌙 하루 마무리**: 한 걸음 나아갔어요 / 잘 쉬었어요 / 버텼어요 / 그냥 흘러갔어요 + 방향으로 움직인 것 + 한 줄 기록
- **📒 기록**: 날마다 쌓이는 상태·한 가지·마무리, 백업 받기/불러오기
- **일어났어요** 버튼: 기상 시각을 기준으로 하루 리듬 블록 7개를 자동 생성
  - ☀️ 깨우기 → 🔥 집중 골든타임 → 💬 소통·잡무 → 😴 오후 처짐 → 🌊 2차 상승 → 🌙 감속 → 💤 잘 준비
- **블록마다 바뀌는 색**과 **하루 막대**: 지금이 하루 중 어디쯤인지 한눈에
- **지금 모드**: 현재 블록 하나만 크게 표시 (남은 시간, 하면 좋은 것, 다음 블록)
- **기상 기록**: 평소보다 일찍/늦게 일어났는지, 오늘 목표 취침 시각
- **오늘의 한 가지** + **25분/90분 집중 타이머** + 완료 체크
- **컨디션 체크** 😫😐🙂: 힘들면 블록마다 "최소 버전"을 권함
- **숨 고르기**: 1분 호흡 가이드 (두 번 들이쉬고 길게 내쉬기)
- **저녁**: 오늘 돌아보기(한 것과 컨디션 흐름만), 걱정 내려놓기, 내일 한 가지 정하기
- **알림**: 블록 전환, 타이머 종료 (앱이 열려 있을 때)
- **홈 화면 설치(PWA)**: 앱 아이콘, 전체 화면, 오프라인
- 데이터는 이 기기 브라우저에만 저장됨

## 원칙
1. 시계가 아니라 기상 시각 기준
2. 한 번에 하나만 보여주기
3. 실패 표시 없음, 놓치면 다음 블록으로
4. 컨디션이 안 좋은 날을 위한 최소 버전
