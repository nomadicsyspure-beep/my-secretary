# LIFE OS

**Personal Life Operating System** · 기록은 가볍게. 분석은 깊게. 삶은 온전히.

감정, 집중력, 부담감, 생각과 경험을 가볍게 기록하고,
쌓인 기록으로 나 자신을 더 깊이 이해하도록 돕는 개인용 웹앱입니다.

https://nomadicsyspure-beep.github.io/my-secretary/

전체 지시서: [docs/LIFE_OS.md](docs/LIFE_OS.md)

## 지금 되는 것 (v1.1)

| 메뉴 | 기능 |
| --- | --- |
| **기록** (홈) | 휴대폰 한 화면에 · 감정 6가지(최고·좋음·무덤덤·피곤·스트레스·불안) · 집중력 · 부담감을 원터치로 (하나만 골라도 저장) · 시간대별 풍경 · + 버튼으로 추가 기록 · 오늘의 순간 · 저녁의 기억 복원 |
| 추가 기록 | 텍스트 메모 · 음성(녹음/파일) · 사진(촬영/앨범) · 사건 · 아이디어 · 자유로운 생각 · 태그 · 지난 시각으로 기록 (발생 시각과 입력 시각 구분) |
| **기억** | 날짜별 타임라인 · 키워드/감정/종류 검색 · 달력 · 모든 기록 수정·삭제 |
| **인사이트** | 7/30/90일/전체 · 감정 · 집중력 · 부담감(날짜별/시간대별/요일별) · 생활 리듬 · 활동(태그)과 상태 · 근거 기록 보기 |
| **나** | 이름 · 기억 환기 알림 시각 · 기억 복원 시각 · 원터치 항목 고르기 · 테마 · 백업(JSON, 사진·음성 포함)/CSV/불러오기 · 전체 삭제 · 이전 버전 기록 옮기기 |

- 기록은 이 기기의 브라우저(IndexedDB)에만 저장됩니다. 어떤 서버로도 보내지 않아요.
- 홈 화면에 설치(PWA)하면 앱처럼 쓸 수 있고, 아이콘을 길게 누르면 바로가기가 나와요.

## 아직 안 되는 것 (후속 단계)
- 앱이 닫혀 있어도 오는 알림 → 안드로이드 앱으로 감쌀 때
- 로그인과 기기 간 동기화 (Supabase)
- AI 분석 (데이터 구조는 준비됨: `analyses` 저장소, 근거 기록 연결)
- 홈 화면 위젯, 스마트워치, 자동 수집 (수면·걸음 수 등)

## 개발

```bash
cd app
npm ci
npm run dev      # 개발 서버
npm test         # 인사이트 계산 테스트
npm run build    # 저장소 맨 위에 배포용 파일 생성
```

소스는 `app/`, 빌드 결과물(`index.html`, `assets/` 등)은 저장소 맨 위에 커밋합니다 (GitHub Pages가 main 브랜치 맨 위를 배포).
