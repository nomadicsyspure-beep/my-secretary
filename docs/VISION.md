# 나의 비서실 기획

## 설계 원칙 (모든 기능의 판단 기준)

> 이 앱은 사용자를 더 생산적인 사람으로 만드는 것이 최종 목적이 아니다.
> 사용자가 자신이 원하는 삶을 지속할 수 있도록 돕는 것이 목적이다.
> 생산성은 그 과정에서 필요한 도구일 뿐이다.

사용자를 더 열심히 살게 만드는 앱이 아니라, 원하는 방향으로 꾸준히 살아가면서도
자기 자신을 잃지 않게 도와주는 앱이어야 한다.

### 기분과 방향을 구분한다

'사용자의 현재 기분'과 '사용자가 원하는 삶의 방향'은 다르다.

- 오늘 너무 피곤하다 → 그렇다고 인생의 목표를 포기할 필요는 없다.
- 오늘 아무것도 하기 싫다 → 그렇다고 게으른 사람이 되는 것은 아니다.
- 오늘 돈을 많이 쓰고 후회한다 → 그렇다고 경제적 독립이 불가능해지는 것은 아니다.
- 오늘 성과가 없다 → 그렇다고 오늘이 무의미했던 것은 아니다.

비서는 무조건 위로하거나 무조건 채찍질하지 않는다. 현재 상태를 고려하면서도
장기적인 방향을 잃지 않도록 돕는다. 감정은 확인하되, 감정에 모든 결정권을 넘기지 않는다.
기분이 나쁘다고 계획을 전부 취소하거나, 기분이 좋다고 무리하게 일정을 늘리지 않는다.

### 그 밖의 원칙

- 실패로 기록하지 않는다. 휴식도 정상적인 선택이다.
- AI는 성격을 단정하거나 심리적 진단을 내리지 않는다. 기록에서 발견한 가능성만 보여준다.
- 무조건 긍정적인 말을 하지 않는다. 생각을 무시하지도, 무조건 동의하지도 않고 다른 관점을 제시한다.

## 6가지 기능

### 1. 인생 방향 설정 (Life Compass)
앱이 사용자가 원하는 삶을 이해하는 기반. 매일 바뀌지 않는, 앱 가장 깊은 곳의 나침반.

- **궁극적인 목표**: 경제적 독립과 자기 성장, 그리고 스스로를 존중하면서 살아가는 삶
- **세 가지 파이프라인**
  1. 청소업: 경제적 안정과 현금흐름
  2. 반복숙련기술업: 기술 축적과 독립적인 수익
  3. 온라인 불로소득업: 디지털 자산과 확장성
- **지키고 싶은 삶의 원칙**
  - 돈을 버는 것과 삶을 즐기는 것을 양립시키기
  - 생산성이 낮은 날에도 자신을 비난하지 않기
  - 다른 사람의 기준보다 나의 방향을 중요하게 생각하기
  - 경제적 목표가 나의 존재 가치를 결정하지 않도록 하기

### 2. 오늘의 상태 확인 (Daily Check-in)
하루를 시작할 때 간단히 상태를 확인한다.

1. 지금 나의 에너지는? ☀️ 매우 좋음 / 🙂 보통 / 😮‍💨 조금 지침 / 🌧️ 많이 지침
2. 지금 가장 신경 쓰이는 것은? 💰 경제적 문제 / 🔮 미래에 대한 불안 / 🪞 자기비판과 열등감 / 💪 일과 피로 / 🍀 특별한 고민 없음
3. 오늘 나에게 필요한 것은? 🌿 차분하게 하루 보내기 / 🎯 작은 목표 하나 달성하기 / 📚 새로운 것 배우기 / 🛌 충분히 쉬기

### 3. 나의 사고 습관 이해하기 (Self-awareness)
반복되는 생각을 발견하고 객관적으로 바라보게 돕는 생각 관찰 노트.

상황 → 자동으로 떠오른 생각 → 생각을 다시 살펴보기(질문) → 새로운 관점

예) 다른 사람은 집도 사고 돈도 모았는데 나는 부족한 것 같다 → 나는 너무 늦었다 →
정말 모두가 앞서 있을까? 경제적 성취가 인간의 가치를 결정할까? 지금 실제로 만들고 있는 것은? →
나는 경제적 기반을 만드는 과정에 있다. 지금의 상황이 앞으로의 결과까지 결정하지는 않는다.

### 4. 나와의 약속 (Personal Commitments)
거창한 목표보다 스스로 지킬 수 있는 작은 약속으로 자기 신뢰를 쌓는다.

| 약속 | 주기 | 목적 |
| --- | --- | --- |
| 게임 개발 20분 | 주 3회 | 자기 성장 |
| 산책 | 주 3회 | 생활 균형 |
| 독서 10분 | 주 3회 | 지식 축적 |
| 재정 확인 | 주 1회 | 경제적 안정 |
| 아무 목표 없는 휴식 | 주 2회 | 생산성 강박 완화 |

기록은 완료 / 미완료(오늘은 하지 못했다) / 휴식(의도적으로 쉬었다) 세 가지. 실패는 없다.

### 5. 주간 인생 점검 (Weekly Review)
1. 생활의 균형: 일과 휴식이 적절했는가? 나를 너무 몰아붙이지 않았는가?
2. 경제적 기반: 조금이라도 진전이 있었는가? 불필요한 소비나 걱정이 있었는가?
3. 자기 성장: 새로 배운 것이 있는가? 원하는 방향으로 조금이라도 움직였는가?
4. 감정과 자기 이해: 반복된 걱정은? 나를 비판했던 순간은?
5. 다음 주 방향: 계속할 것 하나, 개선할 것 하나, 내려놓을 것 하나

매주 기록을 모아 AI가 요약해 준다.

### 6. 나를 이해하는 장기 기록 (Personal Profile)
몇 달의 기록에서 스스로 몰랐던 패턴을 찾는다.
어떤 상황에서 불안해지는가, 무엇을 할 때 즐거운가, 어떤 환경에서 집중하는가,
왜 계획을 포기하는가, 쉬고 나면 무엇이 달라지는가, 실제로 조금씩 성장하고 있는가.

## 앱 구조

- **오늘의 하루** (메인, "오늘도 나의 방향대로.")
  오늘의 상태 · 오늘의 우선순위 · 오늘의 일정과 할 일 · 비서의 제안 · 하루 마무리
- **삶의 방향**: 인생 목표와 파이프라인
- **자기 이해**: 생각과 감정의 패턴
- **생활 시스템**: 습관과 나와의 약속
- **인생 기록**: 주간·월간 성장 기록

뇌 리듬 하루(기상 기준 7개 블록)는 "오늘의 하루" 안에서 일정의 뼈대 역할을 한다.
