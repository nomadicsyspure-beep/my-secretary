# LIFE OS 개발 지시서

> 기록은 가볍게. 분석은 깊게. 삶은 온전히.

## 0. 개요
LIFE OS(Personal Life Operating System)는 감정, 에너지, 집중력, 생각, 생활 패턴과 경험을 기록하고,
장기간 쌓인 데이터로 자기 자신을 더 깊이 이해하도록 돕는 개인용 생활 관리 시스템이다.

- 생산성 앱이나 일정 관리 앱을 만들지 않는다. 더 많은 일을 하도록 독려하지 않는다.
- 자신의 상태를 알아차리고, 맞는 생활 리듬을 발견하고, 매 순간을 조금 더 충만하게 경험하도록 돕는다.
- 특정 개인이 실제 생활에서 꾸준히 쓰고 싶은 완성도 높은 웹앱 MVP가 우선이다.

## 1. 제품 철학
1. **알아차림**: 지금 몸과 마음에서 일어나는 일(감정, 에너지, 집중, 부담, 생각)을 관찰한다. 좋고 나쁨으로 평가하지 않는다.
2. **이해**: 쌓인 기록에서 패턴을 발견한다. 상관관계를 원인으로 단정하지 않는다. 데이터가 부족하면 모른다고 답한다.
3. **선택**: 상태를 이해한 뒤 지금에 맞는 선택을 돕는다. 모든 제안은 선택사항이며 강요하지 않는다.

핵심 원칙
- 관찰하되 판단하지 않는다.
- 계획하되 집착하지 않는다.
- 성장하되 현재를 희생하지 않는다.
- 기록하지 않는 날도 괜찮다.
- 휴식도 삶의 중요한 일부다.
- 앱 사용량이 많다고 좋은 사용자가 되는 것은 아니다.

## 2. 디자인 방향
Warm Minimalism · Nature Inspired · Calm & Friendly · Soft Rounded UI · Organic Shapes · Gentle Illustration · Editorial Layout

- 배경: 따뜻한 크림, 부드러운 아이보리, 연한 베이지
- 주요 색: 올리브 그린, 세이지 그린, 짙은 숲색 / 보조: 부드러운 노랑, 살구, 따뜻한 갈색
- 강한 원색·형광색 금지. 둥근 카드, 적당한 여백, 부담 없는 그림자, 단순한 아이콘, 자연 풍경 배경.
- 귀엽지만 유아적이지 않게. 복잡한 대시보드처럼 보이지 않게.
- 스마트폰 우선. 태블릿은 자연스럽게 확장, PC는 넓은 공간 활용.

## 3. 메뉴 (하단 네비게이션)
1. **기록** (메인 홈) 2. **기억** 3. **인사이트** 4. **나**

### 3-1. 기록 (홈)
- 상단: 로고, 날짜·시간, 설정. 자연 풍경 일러스트와 "지금, 어떤 상태인가요?"
- 감정 6가지: 🤩최고 😊좋음 😶무덤덤 😪피곤 😤스트레스 😰불안
- 집중력(전혀 안 됨~매우 좋음), 부담감(전혀 없음~매우 높음) 각 5단계 원터치
  - 에너지는 집중력과 거의 같아서 뺐다 (사용자 결정). 예전 에너지 기록과 예전 감정(슬픔·무기력·평온)은 지우지 않고 그대로 보여준다.
- 큼직한 확인 버튼 → 저장 + 부드러운 완료 피드백. 시간 자동 기록.
- **각 항목은 독립적으로 기록 가능.** 기분만 기록하고 나가도 정상 동작.
- **휴대폰 한 화면 안에 다 들어와야 한다** (스크롤 없이). 360×740 화면까지 확인한다.
- 작은 + 버튼으로만 추가 기록을 연다. 글쓰기를 강제하지 않는다.

### 3-2. 아침 수면 기록 (사용자 추가 요청)
아침(4–15시)에 그날 처음 앱을 열면 "어젯밤 수면" 창이 한 번 뜬다. 잠든 시각·일어난 시각만 고르면 저장된다.
닫으면 홈에 한 줄 카드로 남고, "오늘은 넘어갈게요"를 누르면 그날은 다시 묻지 않는다. 나 메뉴에서 끌 수 있다.
수면 기록은 인사이트의 "수면"에서 평균 수면·잠든/일어난 시각, 밤별 그래프, 적게 잔 날과 많이 잔 날의 상태 비교로 쓰인다.

## 4. 추가 기록
텍스트 메모 · 음성(녹음 또는 파일) · 사진(촬영/업로드 시각 저장) · 사건 · 아이디어 · 자유로운 생각.
사건은 **발생 시각과 실제 입력 시각을 구분**한다 (실시간 기록과 사후 회상 기록을 구별하기 위해).
음성은 나중에 자동 글 변환을 붙일 수 있게 구조를 둔다.

## 5. 기억
시간순 기록 (날짜별, 감정, 메모, 사진, 음성, 사건). 날짜·감정·키워드·종류로 검색.
달력에서 기록이 없는 날을 실패나 미완료로 표현하지 않는다. 하루 타임라인은 실제 데이터로만.

## 6. 인사이트
감정·에너지·집중력·부담감 패턴, 생활 리듬, 활동과 감정의 관계. 기간: 7일 / 30일 / 90일 / 전체.
- 분석 문장은 실제 데이터가 있을 때만. 예시 데이터를 사실처럼 보여주지 않는다.
- 부족하면 "아직 패턴을 발견하기에는 기록이 조금 더 필요해요."
- 그래프는 읽기 쉽게, 사용자가 고른 항목만.
- AI 확장 준비: 분석 결과에 근거 기록을 연결하고, 관찰된 사실·추정·알 수 없는 것을 구분하며, AI가 원본 기록을 수정하지 못하게 한다.

## 7. 기록 누락 방지
1. **기억 환기 알림**: 사용자가 정한 시각(기본 오전·오후·저녁 한 번씩), 끄고 바꿀 수 있음. 부담 없는 문구. 무시했다고 반복하지 않는다.
2. **기억 복원**: 저녁에 오늘을 돌아보는 선택 질문 (기분 좋았던 순간, 힘들었던 순간, 기억하고 싶은 경험, 떠오른 아이디어)
3. **자동 수집 확장**(향후): 수면, 걸음 수, 활동량, 운동, 워치, 선택적 위치. 명시적 동의 없이는 수집하지 않고, 자동 데이터로 감정을 단정하지 않는다.

## 8. 나
프로필, 알림 설정, 기록 설정, 테마, 데이터 내보내기·삭제, 개인정보. 모든 기록은 사용자의 것.

## 9. 데이터 구조
모든 기록을 하나의 시간순 저장소에 쌓고, **원본 기록과 분석 결과를 절대 합치지 않는다.**

원본 기록: id, user_id, record_type, content, mood, energy, focus, stress, occurred_at, created_at, updated_at, source, attachment_url
분석 결과: id, user_id, analysis_type, analysis_content, evidence_record_ids, confidence, created_at, analysis_version

기록은 시간순 관리, 수정·삭제·검색 가능. 기록 종류가 늘어도 구조를 크게 바꾸지 않는다.

## 10. 기술
React · TypeScript · Tailwind CSS · Supabase · Recharts. 우선 웹앱, 향후 모바일·워치 확장.
저장·수정·삭제·불러오기·날짜 필터·검색은 처음부터 실제로 동작해야 한다. 새로고침해도 기록이 남아야 한다.
Supabase 연결 정보가 없으면 로컬 저장으로 먼저 만들고 옮기기 쉬운 구조로 둔다.
보안: 사용자별 데이터 분리, 접근 권한, 인증, 비밀키를 프론트엔드에 노출하지 않기.

## 11. MVP 순서
1. 기본 화면 (홈, 하단 메뉴, 반응형, 디자인 시스템)
2. 원터치 기록 (기분, 에너지, 집중력, 부담감, 자동 시간)
3. 추가 기록 (텍스트, 사진, 음성, 사건, 과거 시점 기록)
4. 기록 보관 (날짜별, 타임라인, 검색, 수정, 삭제)
5. 인사이트 (기간별 분석, 기본 그래프, 시간대별·요일별 패턴)
6. 기억 환기 (알림 설정, 기억 복원 질문, 하루 회고)

AI 분석, 홈 화면 위젯, 스마트워치 연동은 후속 단계.

## 12. 절대 지켜야 하는 UX 원칙 (다른 모든 지시보다 우선)
1. 기본 기록은 최대한 원터치로 끝나야 한다.
2. 글쓰기를 강제하지 않는다.
3. 홈 화면에 복잡한 통계나 점수를 노출하지 않는다.
4. 매일 목표 달성률을 보여주지 않는다.
5. 기록이 없는 날을 실패로 표현하지 않는다.
6. 알림은 사용자를 압박하지 않는다.
7. 휴식과 아무것도 하지 않는 시간도 존중한다.
8. 사용자가 원할 때만 과거 데이터를 분석할 수 있어야 한다.
9. 모든 기록은 수정과 삭제가 가능해야 한다.
10. 디자인보다 실제 사용성과 기록의 편의성을 우선한다.

## 13. 개발 지침
- 기능이 없는 가짜 버튼, 작동하지 않는 메뉴를 완성된 것처럼 만들지 않는다.
- 임의의 통계를 실제 데이터처럼 표시하지 않는다.
- 오류는 이해할 수 있는 말로 안내한다. 불필요한 복잡함을 더하지 않는다.
- 유지보수 쉬운 코드, 중요한 기능에는 초보자도 이해할 수 있는 주석.

작업 후 확인: 모바일 동작, 원터치 기록 저장, 새로고침 후 유지, 수정·삭제, 날짜별 정렬, 추가 기록 저장,
데이터 없는 상태의 자연스러움, 모든 버튼이 실제 기능과 연결되어 있는지.

> LIFE OS는 나를 통제하는 앱이 아니다. 나를 이해하기 위한 도구다.
